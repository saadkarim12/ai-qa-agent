# Payments Revamp — Draft Requirements (unreviewed)

## REQ-201 Performance
As a Customer, I want the payment page to load quickly so that I do not abandon my basket.

Acceptance Criteria:
- The page should be fast and user-friendly.
- The system must handle errors appropriately, etc.

## REQ-202 Notifications
As a Customer, I want to be notified about my payments so that I stay informed.

Acceptance Criteria:
- Notifications may be sent by email and/or SMS where applicable.
- The system should support several notification types as needed.

## REQ-203 Refunds
As a Customer, I want refunds processed properly so that I get my money back.

Acceptance Criteria:
- Refunds must be processed, although the timing is optional and may vary.
- The refund screen should be intuitive and display various details correctly. TBD.

## REQ-204 Reporting
As a Manager, I want reasonable reporting so that I can make decisions.

Acceptance Criteria:
- Reports should show relevant data if possible and handle large date ranges efficiently, and so on.
